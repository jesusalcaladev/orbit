Orbit × React

hooks devtools

The same TikTok world through @orbit/react — the TikTok-style feed is a useOrbitQuery with a TTL cache, likes are useOrbitMutation with entity invalidation, and live updates arrive through a useOrbitSubscription. Open the 🔮 devtools (bottom-right) to watch queries, subscriptions and activity as they happen — the same panel works in React Native.
